      No-Code Guide: Updating Questions & Adding Sets

      You do not need to edit any code to add new questions, modify existing ones, or create more sets. Everything can be done right here in this dashboard or in Microsoft Excel / Google Sheets.

      1. Choose Class or Exam

      Pick School Classes (9-12) or Competitive Exams (SSC, Railways, etc.). Select the Subject and Set number you want to update.

      2. Edit Any Question

      The editor automatically fills with the questions. You can change text, change options, and click on option (A, B, C, D) to set the correct answer.

      3. Add More Sets

      Click ➕ Add New Set. Pick the set number (e.g. Set 11, Set 12). Add your questions and click Save. The new set button automatically appears for students!

      4. Work in Excel (Bulk CSV)

      Click 📄 CSV Template to download a spreadsheet. Open in Excel, write your questions, save as CSV, and click 📥 Import CSV!

      Quick-Paste Format Sample

      You can copy questions from a Word document or PDF notes and click 📋 Quick Paste. Paste them in this clean format:

      1. Which cell structure controls most cell activities?
      A) Nucleus
      B) Cell wall
      C) Vacuole
      D) Ribosome
      Answer: A
      Topic: Cell Biology

      2. What is the SI unit of force?
      A) Joule
      B) Newton
      C) Watt
      D) Pascal
      Answer: B
      Topic: Mechanics
